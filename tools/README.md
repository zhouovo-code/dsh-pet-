# tools/ · 立绘处理脚本

这些脚本是我做这套立绘时用的工具，**不是运行挂件所必需的**（挂件只依赖 `lib/` 和 `assets/`）。
放在这里是为了让"换一张新立绘"这件事可复现。

> ⚠️ 脚本里写死了我本机的绝对路径（`C:\Users\l\...`）和素材文件名，**在别的机器上需要先改路径**。

## 脚本一览

| 脚本 | 用途 |
| --- | --- |
| `split_expressions.py` | 主力脚本：把"多姿势合图"自动拆成单张，按**白色头饰宽度**归一化缩放并对齐到统一画布（Pillow） |
| `cut-sprite-whole.ps1` | 单图层整只抠图（GDI+，直接用源图 alpha 通道，避免黑边） |
| `cut-sprite-parts.ps1` | 按部位切 9 层（备用：想让尾巴单独摇时用） |
| `cut-sprite-whitekey.ps1` | 白底键控三层版（备用） |
| `cut-sprite-polygon.ps1` | 照片式背景描点多边形抠图（备用） |
| `cut-sprite-expression.ps1` | 第二表情抠图 + 头部对齐归一化 |
| `cut-sprite-wide.ps1` | 双表情宽画布重建（含边界保护） |
| `wide_canvas_shy.py` | 加宽画布以容纳宽姿势（含"是否被裁掉"的完整性校验） |
| `compact_canvas.py` | 把素材收回紧凑画布 |
| `replace_shy.py` / `update_shy.py` | 替换害羞立绘（**黑底/白底自动识别键控** + 对齐到现有尺寸） |
| `place_shy_abs.py` | 按**绝对缩放**放置立绘（锚在主立绘上，不依赖旧文件） |
| `check_halo.py` | 自检：把轮廓放大放在深色底上，检查有没有白边/黑边残留 |

## 关键经验（踩过的坑）

1. **透明背景的 PNG，透明像素的 RGB 常常是 `0,0,0`**。用"白色键控"会把它们当成实心黑 → **黑边**。正确做法：直接用源图 alpha 通道当遮罩。
2. **黑底 JPEG** 需要黑底泛洪（阈值要收紧，否则会吃掉深色衣服），并且遮罩要**内收 1–2px + 轻微模糊**，否则浅色主题下会露出一圈暗边。
3. **深色高光/阴影会让自动锚点失效**：睡姿散开的头发会撑大"头宽"、低头的姿势会压扁呆毛、阴影里的头饰测出来偏窄。必要时用**目视标定**固定缩放值。
4. **画布尺寸比姿势窄时，右侧会被静默裁掉**。放置后一定要比对"实际尺寸 vs 应有尺寸"，`wide_canvas_shy.py` 里就是这么校验的。
5. **永远不要原地覆盖同名素材**：浏览器会缓存。本插件已把素材响应头设为 `no-cache`，但换新文件名仍然最稳。

## 依赖

- Python 3 + Pillow：`python -m pip install --user Pillow`
- Windows PowerShell 5.1（`.ps1` 脚本，使用 GDI+ / System.Drawing）
